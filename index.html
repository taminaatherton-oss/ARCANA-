Настройки ИИ

Подключи любой совместимый сервер с API формата OpenAI Chat Completions. Ключ хранится в локальном хранилище браузера — не используй общий или чужой телефон.

Для локального сервера укажи адрес, доступный с телефона/планшета в твоей сети. Сервер должен разрешать CORS. Для удалённого API браузерный вызов может быть заблокирован политикой CORS; надёжнее позднее добавить собственный защищённый backend. Не публикуй ключ в GitHub.
