PERSONAL INTELLIGENCE

Настройки и ИИ

Выбери способ анализа. Локальный поиск по книгам работает без модели; генерация требует подключённой модели.

Модель и подключение

Для настоящего локального ИИ нужна отдельно установленная модель и локальный сервер, совместимый с OpenAI API. Само приложение не содержит гигабайты модели и не загружает её автоматически.

Интернет-источники

Встроенный исследовательский поиск обращается к открытым Wikimedia и Crossref API. Это не поиск по всему интернету. Можно подключить собственный поисковый endpoint, если он возвращает JSON с результатами.

Резервная копия и перенос

База хранится отдельно на каждом устройстве. Экспортируй резервную копию с одного устройства и импортируй на другом.

Уведомления

Разреши уведомления, чтобы ARCANA могла напоминать о записях. В браузерной версии проверка расписания надёжнее всего работает, пока приложение открыто или при следующем запуске. Для гарантированных уведомлений при полностью закрытом приложении нужен push-сервис или нативный Android alarm.
