# ARCANA · astro — натальная карта и карта дня

Отдельный модуль. Папка `astro/` кладётся в корень репозитория рядом с `index.html` и ничего из существующих файлов не заменяет.

## Установка
1. Распакуй архив — получится папка `astro/`.
2. Загрузи её в корень репозитория (рядом с `index.html`).
3. В `index.html` добавь две строки из `index-snippet.txt`.
4. Подожди 1–2 минуты, пока GitHub Pages обновится, и обнови страницу (Ctrl/Cmd+Shift+R).

## Структура
```
astro/
├─ standalone.html                 проверочная страница без основного сайта
├─ index-snippet.txt               две строки для index.html
├─ sections/
│  ├─ natal.html                   структура раздела «Натальная карта»
│  └─ day-card.html                структура раздела «Карта дня»
└─ assets/
   ├─ css/arcana-astro.css         стили (все классы с префиксом aa-)
   └─ js/
      ├─ arcana-astro-loader.js    точка входа: меню, панель, подгрузка
      ├─ arcana-ephemeris.js       расчёт положений планет и домов
      ├─ arcana-astro-data.js      данные рождения, знаки, арканы, тексты
      ├─ arcana-astro-core.js      натальная карта, аспекты, транзиты, выбор аркана
      ├─ arcana-natal.js           отрисовка натальной карты
      └─ arcana-daycard.js         отрисовка карты дня
```

## Данные рождения
01.04.1998, Воронеж (51.672°N, 39.184°E), около 04:20, UTC+4 (летнее московское время 1998 года).
Правятся в самом разделе («Уточнить данные рождения») и хранятся только в браузере. Исходные значения — в `arcana-astro-data.js`, объект `BIRTH`.

## Как выбирается карта дня
Считаются положения планет на полдень по Москве выбранного дня и их аспекты (соединение, секстиль, квадрат, трин, оппозиция) к натальным планетам, Асценденту и MC. Самый сильный транзит (чем точнее аспект и важнее натальная точка, тем сильнее; Луна не участвует) определяет аркан: берётся старший аркан транзитной планеты (Солнце — Солнце, Меркурий — Маг, Венера — Императрица, Марс — Башня, Юпитер — Колесо Фортуны, Сатурн — Мир, Уран — Шут, Нептун — Повешенный, Плутон — Суд). Луна не выбирает главную карту, а задаёт «Фон дня»: аркан знака транзитной Луны и её дом в твоей карте (Верховная Жрица выпадает, только если других транзитов нет).

## Важно
- Расчёт упрощённый (точность около 1°), подходит для символической практики.
- Время рождения приблизительное: Асцендент и дома могут сдвинуться при другом времени.
- Основные файлы сайта не изменяются; модуль можно удалить, убрав две строки из `index.html`.
