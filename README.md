# ARCANA — обновление интерфейса и исследовательских инструментов

Этот пакет предназначен для обновления уже опубликованной ARCANA на GitHub Pages. Это не новая база данных и не новая установка приложения.

## Что добавлено

- Новый адаптивный тёмный интерфейс для телефона, планшета и широкого экрана.
- Собственный набор SVG-иконок в `assets/icons/`.
- Расширенный импорт: PDF, EPUB, DOCX, FB2, HTML, TXT и MD.
- OCR для PDF без текстового слоя (по отдельному подтверждению; требует интернет и заметную память).
- Карточки книг с автором, категорией и тегами.
- Улучшенный поиск по содержимому и метаданным (ранжирование в стиле BM25, не векторный поиск).
- Для PDF сохраняются номера страниц в новых фрагментах; в ответах модель получает страницу и название источника.
- Исследовательский режим: локальные фрагменты + открытые API Wikimedia и Crossref + подключённая Chat Completions модель.
- Лаборатория раскладов: одна карта, три карты, пять карт, две дороги; ручной выбор или случайное вытягивание, прямые/перевёрнутые карты, анализ и сохранение.
- Дневник практики, личные записи, календарь и напоминания.
- Экспорт и импорт резервной копии JSON для переноса данных между устройствами.
- Service Worker для кеширования оболочки и открытия приложения офлайн.

## Очень важно перед обновлением

1. Открой текущую ARCANA на каждом устройстве.
2. Перейди в «Настройки ИИ» и сделай экспорт резервной копии JSON.
3. Сохрани файл отдельно. Телефон и планшет имеют независимые базы данных.
4. Не удаляй данные сайта, не очищай хранилище браузера и не удаляй старую ARCANA до проверки новой версии.

## Установка на GitHub Pages

Распакуй архив. Загрузи файлы из папки `ARCANA-ULTIMATE` в корень существующего репозитория, где лежат `index.html`, `app.js` и `styles.css`.

**Замени:**
- `index.html`
- `app.js`
- `styles.css`
- `sw.js`
- `manifest.webmanifest`

**Добавь новую папку:**
- `assets/icons/` (все SVG внутри)

**Не удаляй и не заменяй:**
- существующую папку `assets/` целиком — там твой логотип и другие изображения;
- любые изображения, шрифты или файлы, которые уже использует проект и которых нет в архиве.

Сделай Commit changes и дождись завершения GitHub Pages deployment.

## Обновление установленной ARCANA на Android

1. Открой приложение при подключённом интернете.
2. Полностью закрой его и открой снова. Если интерфейс старый, открой тот же адрес сайта в Chrome и обнови страницу.
3. Если старая оболочка продолжает показываться, закрой все окна ARCANA/Chrome, подожди минуту и запусти приложение снова — новый Service Worker обновляет кеш.
4. Проверь библиотеку и дневник. Старые книги и заметки должны остаться.
5. Повтори импорт резервной копии только если данные отсутствуют. Импорт добавляет записи и обновляет совпадающие ID, поэтому не импортируй одну копию многократно без необходимости.

## Как работает хранение данных

Сохранена база `arcana-db`. Версия базы повышена с 1 до 2; существующие object stores не удаляются и не пересоздаются. Добавлен только новый store `spreads`. Старые заметки и книги остаются совместимыми. Новые поля карточек книги и заметок добавляются без миграции старых записей.

Данные хранятся локально в браузере/PWA. Они не синхронизируются автоматически между телефоном и планшетом. Используй экспорт JSON и импорт на втором устройстве.

## Что действительно работает, а что требует подключения

| Функция | Состояние |
|---|---|
| Новый адаптивный дизайн и SVG-иконки | Включено |
| PDF / EPUB / DOCX / FB2 / HTML / TXT / MD | Импорт реализован; сложные книги могут иметь особенности структуры |
| OCR сканированного PDF | Реализован как опциональная загрузка Tesseract.js; нужен интернет и память |
| Авторы, категории, теги | Включено в карточки документов |
| Поиск по библиотеке | Локальный ранжированный полнотекстовый поиск |
| Точные страницы PDF | Сохраняются для новых импортов с корректным текстовым слоем/OCR |
| EPUB / FB2 локаторы | Глава/раздел, не фиксированный номер страницы |
| Анализ раскладов | Схемы, выбор карт и локальные символические ключи; генеративный анализ требует подключённой модели |
| Интернет-исследование | Wikimedia + Crossref; это выборка открытых источников, не весь интернет |
| Более широкий поиск | Необязательный пользовательский JSON endpoint в настройках |
| Локальный ИИ | Интерфейс подключения готов; модель и локальный OpenAI-совместимый сервер нужно установить отдельно |
| Дневник / календарь / личные записи | Включено |
| Напоминания | Проверяются при открытом приложении и при запуске/возврате; фоновые точные alarm при полностью закрытом PWA не гарантируются |
| Полный офлайн | Кешируется оболочка; внешние CDN, OCR, интернет-поиск и удалённая модель без сети недоступны |

## Исследовательский ИИ

В «Настройки и ИИ» выбери:
- **Только моя библиотека** — поиск фрагментов без генеративной модели.
- **Удалённая модель** — укажи URL, модель и ключ API.
- **Локальная модель / сервер на устройстве** — укажи адрес локального сервера, доступного приложению.

Для интернет-поиска в режимах с моделью приложение обращается к Wikimedia и Crossref. Результаты передаются модели вместе с найденными фрагментами книг. Источники выводятся отдельно. Нельзя считать это полным поиском по всей сети; для расширения предусмотрено поле собственного поискового endpoint, который должен возвращать JSON с массивом `results` или `items`, где элементы содержат `title`, `snippet`/`description`, `url`/`link`.

Не помещай API-ключи в файлы GitHub. В браузере ключ хранится локально, но не является защищённым секретным хранилищем.

## Локальный ИИ на Android

Пакет не включает модель: вес модели может составлять сотни мегабайт или несколько гигабайт. Установи совместимое Android-приложение/локальный сервер модели отдельно и включи в нём OpenAI-compatible API. Затем укажи его адрес в ARCANA. Для обращения к серверу на том же устройстве часто используется `127.0.0.1`, но точный порт и путь зависят от приложения-сервера. Если API не доступен из WebView/PWA или блокируется CORS, понадобится мост/локальный backend.

## Ограничения трактовок Таро

ARCANA помогает сопоставлять символические системы, книги и интерпретации. Расклад не является доказанным способом установить будущие события, чужие мысли или объективные факты. Хороший анализ должен показывать аргументы, разные школы и неопределённость, а не обещать абсолютную точность предсказания.

### Локальный словарь карт

Лаборатория содержит 78 карт и краткие базовые символические ключи для Старших и Младших Арканов. Без подключённой модели доступен структурированный локальный разбор по позициям, мастям и общим темам. Это стартовый справочник, а не замена специализированным книгам или сравнительному анализу конкретной школы. Для развернутого толкования с источниками подключи модель.
