# ARCANA — первый рабочий MVP

Локальное PWA-приложение для личной библиотеки по Таро, рунам и эзотерическим традициям.

## Что уже работает
- Адаптивный интерфейс для телефона и планшета.
- Установка как PWA через браузер (HTTPS или localhost).
- Импорт TXT, MD и текстовых PDF.
- Разбиение материалов на фрагменты и хранение в IndexedDB браузера.
- Локальный поиск по загруженным книгам.
- Чат с режимом локального поиска или подключением OpenAI-compatible Chat Completions API.
- Заметки/дневник.
- Экспорт книг, фрагментов и заметок в JSON.

## Что пока не реализовано
- OCR сканированных PDF.
- EPUB/DOCX.
- Семантические эмбеддинги и векторный поиск (сейчас поиск по словам).
- Автоматическая синхронизация между устройствами.
- Защищённый сервер-посредник для API-ключей.
- Нативный APK и полноценная локальная генерация на Android.

## Запуск на компьютере
Из папки проекта:
```bash
python -m http.server 8000
```
Открой `http://localhost:8000`.

## Запуск на Android
PWA можно установить, если сайт опубликован по HTTPS. Самый простой вариант для тестирования:
1. Создай приватный репозиторий GitHub и загрузи содержимое этой папки.
2. Включи GitHub Pages в Settings → Pages → Deploy from a branch → main → /(root).
3. Дождись адреса Pages и открой его в Chrome на телефоне и планшете.
4. Меню Chrome → «Установить приложение» или «Добавить на главный экран».

GitHub Pages — публичный хостинг статических файлов. Не загружай в репозиторий книги, личные заметки, API-ключи или резервные копии.

## Подключение ИИ
Открой «Настройки ИИ».
- «Удалённый API»: укажи полный URL endpoint `/v1/chat/completions`, модель и ключ.
- «Локальный сервер модели»: укажи адрес локального сервера, доступный в Wi-Fi сети. Сервер должен поддерживать формат Chat Completions и разрешать CORS для домена приложения.
- «Только библиотека»: приложение ищет фрагменты в книгах без генеративной модели.

Важно: ключ в браузерном приложении сохраняется локально и не является защищённым от пользователя устройства или вредоносного ПО. Для постоянного использования удалённого API правильнее добавить собственный backend, который хранит ключ на сервере. Не публикуй ключ в GitHub.

## PDF
Для извлечения текста PDF используется PDF.js с CDN. При первом открытии PDF необходим интернет. PDF со сканами без текстового слоя не распознаются.

## Приватность и резервное копирование
База IndexedDB отдельная для каждого браузера/устройства. Данные не синхронизируются автоматически между телефоном и планшетом. Используй экспорт JSON и переноси резервную копию вручную; импорт JSON будет добавлен в следующем этапе.
