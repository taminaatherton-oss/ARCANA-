# Краткая установка

1. Сделай экспорт резервной копии JSON в текущей ARCANA на телефоне и планшете.
2. Распакуй `ARCANA-ULTIMATE.zip`.
3. В GitHub открой репозиторий ARCANA → Add file → Upload files.
4. Загрузи содержимое папки `ARCANA-ULTIMATE` в корень репозитория.
5. Подтверди замену пяти файлов: `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`.
6. Добавь папку `assets/icons/`. Существующую папку `assets/` не удаляй и не заменяй.
7. Нажми Commit changes и дождись публикации GitHub Pages.
8. Открой ARCANA онлайн на каждом Android-устройстве и перезапусти приложение.
9. Проверь старые книги и заметки. Если они отсутствуют, восстанови их из соответствующей резервной копии JSON.

Не очищай данные приложения и не удаляй старую установку до проверки. Подробнее — в `README.md`.
