ARCANA — пакет исправления путей ресурсов

Что исправлено:
- index.html теперь загружает семь SVG-иконок из существующей папки assets/ (а не из отсутствующей assets/icons/).
- sw.js получил новую версию кэша и предварительно сохраняет иконки для офлайн-режима.
- внешний вид, app.js, styles.css, каталог знаний и JSON-справочники не заменяются.

Установка:
1. Сначала сделай экспорт резервной копии в ARCANA на каждом устройстве (Настройки → Резервная копия).
2. Распакуй содержимое архива в корень репозитория ARCANA- с сохранением папки assets.
3. Разреши замену index.html и sw.js. SVG-файлы попадут в assets/ и могут заменить одноимённые копии.
4. Не удаляй и не заменяй app.js, styles.css, manifest.webmanifest, catalog.json, JSON-справочники и существующие изображения.
5. Дождись публикации GitHub Pages. Затем открой сайт и обнови страницу. Если установленное PWA продолжает показывать старую версию, закрой его полностью и открой сайт в браузере заново.

Важно:
Локальная база книг, заметок, раскладов и настроек находится в IndexedDB браузера, а не в ZIP. Этот пакет её не удаляет. Не нажимай «Удалить все локальные данные».
