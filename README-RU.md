# ARCANA — отдельный модуль базы знаний

Этот комплект добавляет автономную страницу `knowledge.html`, которая использует уже подготовленные JSON-библиотеки из папки `knowledge/`.

## Установка в GitHub (без изменения index.html и app.js)
1. Открой репозиторий `taminaatherton-oss/ARCANA-`.
2. Создай в корне папку `knowledge`, если её ещё нет.
3. Загрузи в неё все JSON-файлы из папки `knowledge` этого архива.
4. В корень репозитория загрузи `knowledge-loader.js` и `knowledge.html`.
5. Commit changes.
6. После публикации открой: `https://taminaatherton-oss.github.io/ARCANA-/knowledge.html`.

## Как работает
- Страница сама обнаруживает JSON-файлы в `/knowledge` через GitHub Contents API.
- Загруженные данные сохраняются в отдельной IndexedDB `arcana-knowledge-cache`.
- При повторном открытии без интернета используется последний локальный кэш.
- Новые JSON-файлы добавляются в папку `knowledge`; при нажатии «Обновить библиотеки» они подхватываются без редактирования `index.html`, `app.js` или CSS.

## Важно
- Этот модуль работает как отдельная страница справочника. Он не добавляет пункт меню в основное приложение: для этого понадобится одноразовая интеграция в интерфейс.
- Первичная загрузка и обновление требуют интернет и доступность GitHub API. GitHub API без авторизации имеет лимиты запросов.
- Офлайн-работа возможна после успешной загрузки на том же устройстве и в том же браузерном профиле.
- JSON-файлы публичного репозитория доступны всем. Не помещай сюда личные записи, закрытые материалы или API-ключи.
- Данные IndexedDB основного ARCANA не затрагиваются.
